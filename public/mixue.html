Mixue Ordering System

A Java-based ordering system developed as part of an Object-Oriented Programming course to simplify the ordering process at a Mixue outlet. The system provides a user-friendly interface that allows customers to browse products, customize their orders, and complete the ordering process digitally. Developed using IntelliJ IDEA, the project applied core Object-Oriented Programming concepts such as classes, objects, inheritance, encapsulation, and polymorphism, while GitHub was used for version control and team collaboration. Through this project, we gained practical experience in applying OOP concepts to develop a functional GUI-based application.
