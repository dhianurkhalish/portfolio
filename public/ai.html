Object Recognition Using Convolutional Neural Networks

A CNN-based image classification project developed using MATLAB to recognize and classify four types of fruits: Apple, Banana, Grape, and Pineapple. The model was trained using a custom dataset of 400 images, with image preprocessing and data augmentation applied to improve classification performance and reduce overfitting. The project involved developing and evaluating a Convolutional Neural Network to categorize fruit images into their respective classes. Through this project, I gained practical experience in image preprocessing, data augmentation, CNN model development, and image classification using MATLAB.
