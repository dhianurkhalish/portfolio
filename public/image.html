Diabetic Retinopathy Classification

This project focused on developing a deep learning-based system to classify diabetic retinopathy using retinal fundus images. The main objective was to classify the images into five stages of diabetic retinopathy using a pre-trained ResNet50 model with a Softmax classifier. Developed using MATLAB, the project involved image preprocessing, model training, and testing using a diabetic retinopathy image dataset. Through this project, I gained an introduction to applying deep learning and image classification to a real-world medical imaging problem.
