Kindergarten Management System

A web-based management system developed as part of an Enterprise Programming course to manage kindergarten-related information and activities. The system provides separate interfaces for teachers and students to manage and view information such as student records, subjects, timetables, and profiles. Developed using Java, JSP, Servlets, and database integration in Eclipse, the project provided practical experience in developing a dynamic web application with different user roles and database-driven features.
